# Native-reviewer wording briefs

One short, self-contained brief per locale — email it to, or use as call notes with, the native-speaker UX researcher for that language. Each leads with the few real decisions (clear-cut vs genuine toss-up, the nuance, a recommendation), then a quick-confirm list. Source research: [../i18n-glossary-proposals.md](../i18n-glossary-proposals.md).

**All 20 full locales have a brief as of 21 Sep 2026.** The ten that did not (ca, da, fi, nb, nl, pl, ru, sv, tr, uk) were created by the Signals-rename round, which touched every locale — so each of those leads with the fact that **nobody has ever reviewed that language**, rather than asking for confirmation of a hunch. `zh-Hant-HK` has no brief and needs none: it is a thin override fork that inherits `zh-Hant`, so it carries only genuine Hong Kong idiom.

**Rounds are appended, never rewritten.** A brief accumulates: round one is the original term table, round two the Codebooks lens (21 Aug 2026), round three the Signals lens (21 Sep 2026). Earlier rounds' open questions are restated at the bottom of the newest round when they are still unanswered, because they usually touch far more strings than the new ones.
