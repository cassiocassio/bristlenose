Azure: what each open decision looks like

The open questions in the private Azure plan (its section 9; numbered Q1 to Q46) that change what a researcher sees, each drawn both ways where there are two real options. It adds to azure-connection-states.html and does not redraw it: getting connected, the failures with Details closed, the Details popover and configure azure are there. Same frame chrome, same tokens, same rules: Microsoft’s words, nothing invented that a shipped surface can carry, native controls, buttons never truncate.
