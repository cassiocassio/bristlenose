Commentary — placement B

What this buys: a real page. The §5a aligned layout (claims left, evidence right — the only presentation that preserved critical engagement in the N=372 study) fits naturally; long answers, the three-way abstention coaching, and any future history all have room. Framing is unambiguous — you are in ask mode, so model prose never sits adjacent to the researcher's own report text.

  • The empty room: state 1 is the argument against the whole placement. A lens that is blank until queried is the "empty room with a signpost" the MCP doc's §Positioning refused — and every quote this page can ever show already lives one lens up, with more affordances.
  • The severed loop: the cards here are copies. Star/tag work (same store, same PUT endpoints — cheap to wire), but selection-into-analysis means either duplicating the Quotes toolbar here piece by piece, or bouncing through Open these in Quotes → — a context switch per claim. The query → select → tag loop that placement A does in place becomes navigate-read-navigate.
  • Implementation is heavier and triple-surface: new SPA route + page; the mac.app sidebar is native, so the lens list changes in Swift; lens name + strings ship in every locale for both surfaces; export mode must hide it (no live LLM from a file:// leave-behind). Placement A touches none of the native chrome.
  • Positioning cost: a sidebar entry is a standing advertisement that Bristlenose contains a chat — the Dovetail/Marvin shape §Positioning refused and §4 re-refused ("never a separate destination"). Adopting B means reversing a decision made twice, knowingly.
  • Where B's ideas survive anyway: the aligned claims/evidence layout and the per-claim Open in Quotes bridge are portable — A can adopt the two-column presentation inside the Quotes lens on wide viewports without B's navigation cost.
