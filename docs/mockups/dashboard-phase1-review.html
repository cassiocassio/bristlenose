AStudy at a glance — justify the number row

Commentary · the change

Shipped is display:flex; flex-wrap:wrap — cards are content-sized and the row ends ragged. Phase 1 switches the container to a justified grid: fixed --bn-space-md gutters, cards flex to fill, flush both edges. Singles span 1 unit, pairs span 2; every card is conditional so the unit count is data-driven (1–8). Card internals are untouched — same 28px display number, same label, pairs still share one border.

BKey quotes — bound the card, honestly

Commentary · the change

The grid is already right (shipped 3-up, 5-up at ≥1400px — count always matches columns, no orphan). The gap is height: BN's quotes run 4–8× longer than a human would pull (IKEA median 79 words), so an unbounded card becomes a wall of text and the first-glance "oh, that moment" is lost. Phase 1 adds a line-clamp — presentation-only, the lens keeps the full quote.

issueClamp cuts the tail, and in think-aloud the payload is usually at the end (“…so I gave up”). It's a knowing pre-TF stopgap — the real fix (an LLM “pull” that elides low-signal clauses to surface cause→feeling→consequence) is Phase 3, post-launch. Don't read the clamp as the answer; read it as “stop the wall of text until the pull ships.”

CSections | Themes — equal-length columns

Commentary · the change

Shipped is two plain accent-link lists side by side. With real cardinalities they're almost always lopsided (16 sections vs 11 themes, or 25 vs 13), so one column runs long and the other leaves a column of whitespace. Phase 1 splits each pane into multiple ~30-char columns, the column count allocated in proportion to each group's item count (largest-remainder), so the columns come out roughly equal length even when the groups aren't. shipped link styling unchanged — accent, underline on hover.
