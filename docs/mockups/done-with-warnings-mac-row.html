What does not warn

SituationWarns?Why
No screens in the studyNoScreens is read by the server on demand, not by the run. A study without screen recordings has nothing missing. This change does not touch it.
A solo think-aloud, diary or monologue with no moderator in any sessionNoThe Discussion stage already calls this "skipped, nothing wrong". It stays silent: nothing was expected.
A study with no discussion guideNoThe lens is built without a guide, which is a normal case.
The stage crashed (a bug or bad data)YesThe lens was expected and is missing. This is the only case the terminal's end line covers today.
The model failed to read some sessionsYesThe lens is partly or wholly missing because calls failed.
A guide file is present but cannot be read (an encrypted Word file)YesThe researcher expected their questions to be used.
