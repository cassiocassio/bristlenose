Keyboard-cursor cue — overrides shipped

Settled 3 Aug 2026 and now shipped, so the default state of this lab is the product: the cursor cue is appearance-conditional — light keeps the existing shadow lift (the focused card drops to the page colour, which is the brightest surface in both light palettes), dark gets a 1px accent ring (there the same rule makes it the darkest card in a field of identically dark ones, and --bn-focus-shadow is black in both palettes). The starred left border dissolves with everything else; descriptions fade with their titles at 0.4.

Row 2 of each cell is the keyboard cursor (.bn-focused) — the card s would star. Row 3 is selected, rows 4–5 are starred. The cues above are still live so the decision can be re-opened against the four cells; A applies the ring in light too, which is what the shipped rule deliberately does not do. One ring only — it marks the cursor, which is singular; selection and starred are plural and must never take it.
