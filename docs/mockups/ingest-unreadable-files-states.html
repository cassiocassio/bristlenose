Unreadable files — what the row and the popover say

The rule, as settled: a file in a format we say we read (the docs list) that we opened and couldn't use is a failure with a reason (“we tried, and it wasn’t a transcript when we looked inside”). A file in a format we never offered, .py and .txt alike, is left alone and never changes the outcome. Where a popover is already open for a real failure, a quiet footer says what was left alone and links to the formats we read. Native approximation of ProjectRow and ProjectDiagnosticPopover; every sentence is a shipped locale key unless it is marked new copy.

Correction to what I said earlier

I said the popover’s “Done with warnings” outcome covers files that were left out. It doesn’t: it covers quotes left out of a session (leftOutCount, completedPartialAnalysed). Files that couldn’t be read have no such path, which is why Talismanic read “Partial completion”. Nothing in this page relies on that outcome.
