How to show “how much evidence landed on this question”

A per-question cue in the GuideSidebar — a scent of where the meat is — without a column of “6/8” fractions (leaderboard / gap-shaming) and without colliding with the codebook’s state dot.

The collision. The codebook sidebar uses a lone dot, blue = on / grey = off (design-codebook-state-model.md) — a binary state. The first-draft evidence ramp was also a blue dot in a sidebar row, just at varying opacity — so “strong evidence” and “codebook enabled” look identical. The fix: keep state = blue dot; make magnitude read as a scale — a different shape (count / height / length / size) in a neutral tone. Sentiment hues are spoken-for too, so magnitude stays monochrome.

Recommendation. V2 signal bars — the height ramp reads as “level/strength” with zero training and can’t be mistaken for an on/off state, so it frees the blue dot to keep meaning “enabled” everywhere. V1 pips is the close runner-up (simplest, most compact). If you want the least change from today, V4 dot-size keeps the dot but re-encodes magnitude as size in a neutral tone. Any of the three resolves the collision; all stay monochrome so sentiment colour is untouched. Empty state (0 evidence) is a hollow outline in every option — absence stays quiet, not shamed.
