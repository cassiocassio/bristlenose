Commentary — not product UI

Recovery is inspection, not replay

Proposed new disclosure uses the existing 360 pt / content-height / 320 pt ceiling. Header remains fixed; only the body scrolls. Recovery text is selectable with ordinary Select / Copy. There is no Apply, Unlock, Reopen, Duplicate or new action row. Nothing is pasted into the report automatically.

The ordinary header Copy remains diagnostic-only. It deliberately excludes participant text. A user who wants recovery text selects it explicitly; copying a status report into a support issue must not disclose it by accident.

The main report remains the last validated report. The illustrated locked-reader runtime and this disclosure are proposals, not implemented capabilities. Native symbols/materials are browser approximations; cartouche reuses the existing official Lucide asset. Field labels require trusted source metadata or a generic field label; do not guess a match in a changed report.
