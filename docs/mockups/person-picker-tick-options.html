1 · The tick

The tick magnified

Each tick is rasterised at its true rendered size on this screen (device pixels), then enlarged without smoothing, so the antialiasing is real, not redrawn. Follows the appearance and type switches.

Commentary

Why the shipped tick looks wrong. It is the character ✓ (U+2713) set at the row's 13px label size. Neither SF Pro Text nor Inter is drawn for menus at that size: the glyph is a long, thin dingbat with a hairline stroke that antialiases to grey. It also comes from a fallback font on some systems, so it does not match the type around it.

A is shipped. B keeps the character but sets it at caption size and emphasis weight. C to E replace it with a drawn check, sized to the row's cap height and stroked in currentColor, so it follows the label colour and both palettes like the character does. C is the proportions of macOS's menu checkmark: a short left leg and a long right leg. D is the same shape heavier. E is smaller still, closer to the check inside the Mac's "That's Me" symbol.

What a decision changes in code: one line in PersonPicker.tsx (the ✓ becomes an inline SVG, or keeps the character with a class) and possibly a rule in global-nav.css. The Export menu's Burn subtitles… row uses the same .export-dropdown-check gutter, so changing the gutter's rule changes that tick too. That is probably right: one tick across the web app.

Held constant here, on purpose: the new-person row still shows the slot's own code (m1). Your request to show the next free code (m2) is a separate change, kept out so this page only compares ticks.

Commentary

Upright is shipped: the field's placeholder, New moderator, is ::placeholder in the muted colour (person-picker.css). Italic would match the grid, where an unknown speaker's role word is muted italic (.bn-speaker-editable-name.unnamed, person-badge.css). That is the "grey italic means unknown" rule. Note the placeholder is not quite "unknown": it is an empty field asking for a name.

The native popover can't be judged from this page. A CSS imitation of the Mac column was wrong in three places last time (the v3 calibration bench).
