Uses
The existing Sentiment cell, which already summarises the session's quotes, and the shipped warning glyph (Icon, Lucide triangle-alert), muted like the grid's other secondary text. Shown only when the count is above zero.
Cost
A new element inside an existing cell, one new string with a count (21 locales), the count on the sessions API. There is no quote-count column to attach it to, so it cannot be a bare "12 quotes, 1 left out".
Invents
One new string and one mark. No new control, no new column, no colour.

Say which quote or why, or offer to fix it. It is a fact, not a task.

C. A line in the run's popover

Pipeline popover after the run (native, schematic: only the lines are proposed)
1 quote left out of Priya's session
Commentary
Uses
The five-kind message vocabulary: a warning line, as the CLI prints it, in the popover that already lists a run's partial results. The popover is native; this frame sketches one line of it and does not claim to show its layout.
Cost
A Swift row, the count passed through the run summary, one new string with a count (21 locales).
Invents
One new string. In the CLI a left-out quote makes the run read "Done with warnings"; the Mac would have to choose whether it does too, which may be heavier than the fact deserves.
Does not
Persist after the popover closes, unlike B.
StringStatus
"{{count}} quote left out of {{session}}'s session"owner-written, new
Commentary: recommendation
Lean
C if a note after the run is enough; B if it must still be there next week. B is the only one that stays visible, and the Sentiment cell is the natural home because it already summarises the session's quotes; its price is a new mark in the grid. A, if the owner reads one dropped quote as noise.
Not asked
Which quotes were left out, a way to retry them, or a count on the project row.
