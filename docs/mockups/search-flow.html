Text contains finds quotes that use the words but were never coded, which is a way to find what coding missed. Not tagged finds what's left to code. The tag token is independent of the tag sidebar: neither changes the other.

C · Words in any order, or an exact phrase

A quoted phrase must appear exactly

“…which is more than the shelf.”

Each word must be the start of a word, so “st” finds Storey but not best. Accents and case don't matter. Chinese and Japanese terms match anywhere, because those scripts don't space words. Filtering starts at 2 letters instead of today's 3.

Two presses, so one slip can't delete a token. Esc closes the menu first, then clears the text, then collapses the field. The ⓧ button clears text and tokens (open question 2 in the spec).
