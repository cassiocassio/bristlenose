Commentary

Kind: S. b19c75add (25 Jul): “a failed sync is otherwise invisible until reload silently reverts the user’s change”, wired once in the write path so every consumer is covered. A burst collapses to one message. Later commits made it say why: a run in progress (aaf60677e), a quote a re-run removed (4b3a1ef32), a tab that outlived its serve (c17079640).

This is the toast the browser cannot do without (§3): no subject on screen, a lost edit otherwise, and no native state to mirror. It passes every rule except rule 6: a 4 s message is gone before a researcher who was looking at a quote sees it.

Issues: no glyph; one confirmation can replace it; hand-rolled “one at a time” in the call site’s comment. Phase 4’s id does that properly.

Thinking: error glyph, longer hold, an error is not displaced by a success. The kind for S sites is not named in phase 2 (it lists the 11 F sites); drawn here as error, and the running-analysis case as warning (waiting fixes it), which is my reading.
