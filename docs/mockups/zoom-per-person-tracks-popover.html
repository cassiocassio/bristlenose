What's wrong with A. The analysis completed: two meetings, two sessions, each transcribed from the meeting's combined audio. The four files are tracks Zoom writes when Record separate participant audio files is on, one per person, and Bristlenose correctly didn't use them. They're filed as failures, so the study reads Partial completion with an orange triangle, and each track is called "a second recording", which it isn't.

B reuses the files popover's info section (ProjectFilesPopover, the "+1 unanalysed" surface): blue ⓘ glyph on the row, a title, one section with the glyph, the files with sizes, and a caption. It has no button, because there's nothing to do. The diagnostic popover in A only opens for failures, which is why B can't be a footer line there: a clean run has no failure popover to put it in.

C drops the mark entirely. The tracks would then be named only in the log. It's the cheapest option, but a researcher who switched that Zoom setting on would never learn the tracks were ignored.
