# Signal evidence-fragment calibration

## What to mark

For each evidence playback below, bold **one contiguous fragment**: the
smallest phrase that does the explanatory work for the signal. It should name
the meaningful experienced state, effect, cause, or their compact relation —
not merely repeat the tag name.

For example, in:

> The participant wanted to complete the order but was frustrated by the
> unclear wording around the minimum spend.

the desired fragment might be `**frustrated by the unclear wording around the
minimum spend**`, not the whole sentence and not simply `frustrated`.

Please leave the rest of each sentence unchanged. If two pieces truly feel
necessary, bold the primary one and add a short note below it; the first model
will deliberately support one fragment only.

These are calibration examples, not claims to store in a study.
