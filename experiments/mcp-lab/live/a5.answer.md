## Tool experience
- Mostly smooth. The instructions steered me to sort="strength", and the result's sorted_by field stated what it meant.
- Quote ids like q-p1-0 in s3 and q-p1-120 in s1 share the p1 code across sessions, which is confusing. The p3 / p1 mismatch in s3 is not explained anywhere in the output. The instructions cover recoded speakers and moved paragraphs, but this case (visible_quotes 2 for the session, 0 for its only participant) isn't clearly addressed.
- Both overview rows for the moderator show code "m?" with slot_code m1. That matches the instructions, but it's easy to misread.
- A text query "login" returned only 1 quote, because it matches quote text only, not section. A section filter is the right way to do this, and I only knew that because I guessed it. The description doesn't say what query searches.
- Nothing tells me the strength ranking's basis for the three intensity-tied quotes beyond "signal strength"; no per-quote score is shown.
- Missing: no "rant" or vividness notion (the tool says so, honestly), and no way to see the hidden quote.
- Cosmetic: the "Onboarding gaps" theme has 0 quotes, and the section counts (7 + 2 = 9) match the visible quotes.
